# Campus: личный коннектор

Нужен Node.js 22 LTS или новее. Распакуйте архив в отдельную папку, затем выполните в ней:

```
npm ci
npm start
```

После сообщения «Campus connector ready» откройте https://campus-planner.mymemory9.workers.dev, создайте свой аккаунт и перейдите в Настройки → Telegram или WhatsApp → Показать QR.

- Telegram: API ID и API Hash своего приложения получите на https://my.telegram.org/apps. Введите их в настройках сайта: они отправляются только на 127.0.0.1, не на сервер Campus. Отсканируйте QR в Telegram → Настройки → Устройства. Если включён облачный пароль, введите его в появившемся поле.
- WhatsApp: Настройки → Связанные устройства → Привязать устройство. После входа выберите нужные группы на сайте.
- До выбора чатов тексты не отправляются. При отключении чата сервер перестаёт принимать его сообщения. История фильтруется с 30.08.2026 00:00 Asia/Almaty; WhatsApp может предоставить связанному устройству неполную историю.
- Поддерживаемые вложения до 20 МБ передаются только для принятых сообщений. Вложения с неизвестным размером или неподдерживаемым типом не скачиваются автоматически.
- Коннектор должен оставаться запущенным. Это обычная программа на вашем компьютере, не облачный сервис. Закрытие терминала прекращает синхронизацию. Повторный npm start возобновляет сохранённые подключения.
- Сессии и ключи хранятся в локальной папке .data с ограниченными правами. Не передавайте её другим людям. Облачный сайт получает только выбранные сообщения, метаданные групп и поддерживаемые вложения; сообщения передаются Cloudflare Workers AI.
- Настройки → Безопасность → Отозвать подключения устройств отключает ключи всех коннекторов вашего аккаунта. Отдельное «Отключить» отзывает связанную сессию, когда локальный коннектор доступен. Всегда можно завершить сессию непосредственно в мессенджере.
- При блокировке доступа браузером разрешите этому сайту подключение к локальной сети/127.0.0.1. Коннектор принимает запросы только от адреса сайта, указанного в .env.

Для другого домена измените CAMPUS_APP_URL в файле .env. Для локальной разработки: CAMPUS_APP_URL=http://localhost:5173.

WhatsApp использует стороннюю библиотеку whatsapp-web.js: работоспособность зависит от изменений WhatsApp, возможны ограничения аккаунта. Telegram API имеет ограничения использования данных для AI: https://core.telegram.org/api/terms. Подключайте и обрабатывайте чаты только при наличии необходимых прав.


Обновление 7 сентября: при ERR_ABORTED выполняются до трёх попыток с закрытием незавершённого браузера. Используется текущая версия WhatsApp Web без локального HTML-кэша. При повторной ошибке проверьте доступ к web.whatsapp.com. Для обновления остановите коннектор, замените файлы из нового архива, выполните npm ci и npm start. Папку .data сохраняйте: там ваши локальные сессии.


Обновление 8 сентября: кнопка «Синхронизировать и анализировать сейчас» в настройках мессенджера забирает сообщения и запускает AI сразу. Пакеты содержат до 20 новых сообщений и контекст; история решений доступна на сайте. За ручной запуск импортируется до 1000 сообщений Telegram на выбранную группу и анализируется до 1000 сообщений; оставшееся можно запустить следующей кнопкой, автоматическая синхронизация также продолжает импорт.

Вход WhatsApp и загрузка групп теперь имеют отдельные состояния. Ошибка списка чатов не аннулирует успешный вход. Система показывает этап входа, а не внутреннюю однобуквенную ошибку. Подпись Chrome (macOS) относится к локальному браузеру коннектора. Если WhatsApp снова отклонит вход, текст ошибки будет виден на сайте; совместимость с изменениями WhatsApp не гарантируется.

Передаются аватары и порядок групп, а также доступные мессенджеру имя, ник и номер отправителей только выбранных сообщений. Скрытые номера не запрашиваются обходными способами. В разделе «Люди и роли» можно подтвердить совпадения номеров и объединить карточки. Доверие и роли автоматически не назначаются.

## Platonus (9 сентября)

В Campus откройте вкладку Platonus → «Открыть вход в Platonus». Коннектор открывает отдельное окно браузера на вашем компьютере. Введите логин, пароль и при необходимости код подтверждения непосредственно на platonus.kstu.kz. Campus не получает пароль или cookies. После входа нажмите в Campus «Получить данные».

Используется русский интерфейс расписания. Коннектор читает две соседние доступные недели и показывает предварительный просмотр. Каждое добавление/обновление подтверждается отдельно; существующие ручные занятия не удаляются. Две недели применяются как повторяющийся шаблон до конца указанного семестра. Неоднозначные подгруппы и пересечения требуют ручного редактирования. Типы «Л», «ЛЗ», «СПЗ», «СРС», «СРСП» сохраняются явно.

Оценки и УМКД считываются из доступных таблиц на страницах журнала и УМКД; заголовки и значения сохраняются без пересчёта. Файлы доступны по ссылкам Platonus (для открытия может потребоваться вход в обычном браузере). Скрытые детали и страницы за дополнительными кнопками автоматически не обходятся. Если таблица не распознана, раздел сообщает об этом и сохраняет последний успешный снимок. Сквозная проверка этих двух разделов на действующем аккаунте пока не завершена: университетский сайт недоступен во время разработки.

Сессия Platonus хранится отдельно для каждого аккаунта Campus в .data. «Отключить» закрывает локальное окно и удаляет этот профиль, но сохраняет уже импортированное расписание. После перезапуска коннектора снова нажмите «Открыть вход»; сохранённый профиль может продолжить сессию. При отзыве ключей устройств коннектор больше не может отправлять данные.

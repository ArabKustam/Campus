# Чат, редактор и диагностика — 7 сентября 2026

Публичный сайт: https://campus-planner.mymemory9.workers.dev

## Чат с AI

В боковом меню появился «Чат с AI». Прямые команды владельца используют существующую классификацию, проверку целей и применение/отмену действий. История отделена от Telegram/WhatsApp; вымышленные сообщения мессенджеров не создаются.

- «ДЗ по экономике: глава 4» — явная команда записать задание. Без указанного срока сохраняется без срока.
- Предмет требует явного упоминания или однозначного преподавателя. Близость пары не доказывает предмет.
- Неоднозначный запрос вызывает уточнение; следующая реплика дополняет только незавершённый запрос.
- Повтор запроса с тем же ID возвращает прежний результат, а не создаёт ещё одно задание.
- Выполненное действие можно отменить. Сохраняются существующие проверки конфликтов.
- При неправильном формате ответа модели выполняется одна повторная попытка до любых изменений данных.

## Редактор занятий

Настройки → Редактор занятий → Преподаватели / Предметы / Занятия.

Редактируются имя/email преподавателя, название/короткое название/цвет предмета, привязка преподавателя, день, неделя, номер пары, время, тип, корпус, кабинет. Можно создавать новые записи. Изменение справочника сразу действует для всех связанных занятий. Проверяются внешние ключи, диапазон времени, пересечение времени и номера пары. Изменения изолированы текущим аккаунтом.

## Коннектор

- WhatsApp: до трёх попыток при net::ERR_ABORTED; каждый незавершённый браузер закрывается без удаления сохранённой авторизации. HTML-кэш WhatsApp отключён. Первичная загрузка ограничена 90 секундами; после QR есть 10 минут на сканирование.
- Telegram: видимая инструкция API ID/Hash → QR в разделе «Устройства» → облачный пароль при необходимости → выбор групп.
- Коннектор перезапущен из папки проекта. Новый архив доступен по ссылке в настройках.
- Отдельные браузеры блокируют доступ облачного сайта к loopback. В таком случае откройте сайт в браузере, поддерживающем разрешение локальной сети, и разрешите доступ. Это отдельная проблема от ERR_ABORTED внутри WhatsApp Web.

## AI и лимиты

Настройки → AI и лимиты: текущая модель, запросы/ошибки/токены за сутки UTC, длительность последних обращений, ошибки всей обработки, фактический размер SQLite (включая файлы).

Защитный лимит приложения — 100 вызовов AI на аккаунт в сутки UTC. Это не остаток общей квоты Workers AI. Общая квота и RAM не доступны через текущие привязки; интерфейс прямо сообщает об отсутствии данных. Показанный предел SQLite бесплатного плана — 1 ГБ на объект. Счётчики начинаются с обновления.

Первичные источники: [Cloudflare storage limits](https://developers.cloudflare.com/durable-objects/reference/faq/), [mtcute QR sign-in](https://mtcute.dev/guide/intro/sign-in), [WhatsApp Client](https://docs.wwebjs.dev/Client.html).

## Проверки

Worker: полный набор 102 теста, включая прямое ДЗ без глагола; frontend: 25 тестов; коннектор: 3 теста повтора/ошибки авторизации/отмены. TypeScript и production build проходят.

На отдельном удалённом аккаунте настоящая Workers AI создала ДЗ без срока, правильно обработала уточнение предмета, повторный ID и обновление преподавателя. Один первоначальный ответ модели не прошёл проверку; добавлены повтор формата и видимость ошибок всей обработки.

Через браузер проверены вход, новый чат, создание/отмена задания, сохранение длинного имени и тёмная тема. Личный вход в мессенджеры не выполнялся. Тестовые аккаунты и их записи удаляются после проверки.

Обновлённый коннектор получил настоящий QR WhatsApp в тесте, без сканирования и входа в личный аккаунт. После проверки тестовое подключение отключено.

8 сентября: выявлено, что модель иногда оставляет reason пустым. В прямом чате отсутствие пояснения теперь заменяется нейтральной отметкой, без изменения предмета, даты, содержания или уверенности. Добавлен регрессионный тест; JSON-схема теперь явно требует непустое пояснение.

8 сентября, регулярные занятия в личном чате:
- Прямые утверждения владельца авторитетны; «вроде» не требует подтверждения сторонним источником. Убран порог уверенности модели для прямых команд; остаются проверки цели и структуры.
- Добавлен разбор регулярных занятий по дням, чётности недели и номеру пары. Время берётся из единственного установленного интервала этого номера пары. Новый предмет создаётся вместе с занятием. Срок действия — с ближайшего подходящего дня до конца текущего учебного периода, что явно сообщается в ответе.
- Ссылки «та же преподавательница» / «в том же кабинете, что и …» разрешаются через справочник и расписание. При нескольких разных значениях запрашивается конкретное уточнение.
- Используются существующие ai_actions, применение, снимки и отмена. Регулярность разрешена только для личного чата; коннекторы не получают этот режим доверия.
- Точный пример культурологии протестирован, включая создание предмета, Ивлеву Е.Н., кабинет 420, чётные пятницы, 09:00–10:45, повтор ID, отмену и повторное применение. Полный набор: 107 worker-тестов; TypeScript и frontend production build проходят.

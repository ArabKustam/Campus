# Администрирование и архив УМКД — 23 сентября 2026

Опубликовано: `5c2e82e3-3fd0-4937-a4c7-c28ec4541cf7`.

## Интерфейс

- `/admin`: отдельные разделы аналитики, пользователей и хранилища.
- Нажатие или Enter на столбце графика открывает детализацию дня, выбор часа, пользователей, время видимой вкладки и события. Время графиков — Алматы. Для старых посещений без замеров длительность не выдумывается.
- Поиск, фильтры, компактные раскрывающиеся строки аккаунтов. Внутри строки — права, посещения, инструкция установки и удаление с подтверждением.
- Права `ai`, `groups`, `messengers`, `tasks` выдаёт только владелец сайта с действующей повышенной сессией. Изменения попадают в аудит. Права администратора через эту форму выдать нельзя.
- AI скрыт по умолчанию; общий учебный тур больше не содержит AI-сценариев.
- В окне документа УМКД при наличии нескольких версий появляется выбор даты. Просмотр PDF остаётся непрерывным.

## Хранение и ограничения

- Общие PDF хранятся в приватных Durable Objects `archive:<courseId>`. Их нельзя получить по публичной ссылке на хеш: запрос пользователя проверяется по его собственным документам и каталогу дисциплины.
- Общий индекс дисциплины проверяет документ максимум раз в час; одновременные запросы объединяются. SHA-256 предотвращает повторное сохранение одинакового содержимого внутри дисциплины. Разные дисциплины изолированы.
- Старые PDF не удаляются при смене содержимого. Снимки, уничтоженные до этого выпуска, восстановить невозможно.
- Уже сохранённые личные копии переносятся по две за фоновый запуск, без обращения к Platonus. Удаление прежнего объекта отложено на сутки для завершения открытых потоков чтения.
- Панель хранилища показывает SQLite-объём измеренных пространств, общий архив, размер D1 и оценку остатка относительно бесплатного лимита. Учёт других проектов Cloudflare не входит в оценку. Полный сбор запускается кнопкой обновления сведений всех аккаунтов; фоновое обновление также пополняет инвентаризацию.
- Замеры активности ограничены видимым временем, объединяют пересекающиеся вкладки; подробные события и интервалы хранятся 90 дней.

## Развёртывание

- В центральную D1 применён только `migrations/0026_access_archive_analytics.sql`.
- `0027_umkd_versions.sql` применяется автоматически в пользовательских пространствах. Не запускать все старые D1-миграции против production: исторический реестр миграций неполный.
- Проверено: 198 серверных и 41 клиентский тест, TypeScript, сборка, браузерные сценарии 390/1280 px (`bridge/admin-upgrade-ui-smoke.ts`). Проверки включают отзыв прав, изоляцию версий, PDF без Platonus, конкурирующие обращения к общему архиву и перенос старых копий.

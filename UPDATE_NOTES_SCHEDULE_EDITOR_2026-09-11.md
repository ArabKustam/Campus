# Редактор в расписании

Кнопка «Редактировать» открывает сетку редактируемых пар для дня или недели. Свободные места имеют кнопку добавления. В форме доступны предмет (включая создание нового), преподаватель, тип занятия, день, номер пары, время, чётность, кабинет и корпус. Изменения сохраняются через существующий catalog API с проверкой пересечений. Для отмены только одного занятия предусмотрен переход в его существующую панель статуса с датой.

Права группы сохраняются. Редактор показывает записи выбранного пространства; для общих занятий нужно выбрать «Общие занятия», для подгруппы — её пространство. Регулярные изменения не требуют AI.

Уточнения AI-списка теперь заменяют адресованную строку по дню и номеру пары, вместо добавления её как нового занятия. Краткое уточнение чётности наследует предмет только от единственной соответствующей строки. Последнее глобальное уточнение периодичности имеет приоритет. Неподтверждённые данные по-прежнему уточняются.

Проверки: сборка клиента, typecheck:worker, 152 серверных теста, 28 frontend-тестов; после последнего изменения маршрута повторно прошли 20 тестов assistant/catalog/recurrence/list.

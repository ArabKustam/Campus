# Временно индивидуальный режим

GROUPS_ENABLED=false в src/lib/features.ts. Групповой код и данные сохранены. Интерфейс скрывает группы, выбор областей, вступление по приглашению и источник УМКД старосты. Обновлённый клиент принудительно использует personal для API и исключает групповые overlay-параметры; сохранённая вкладка группы заменяется расписанием. Первый вход предлагает личный Platonus либо ручную настройку. Серверные групповые маршруты сохранены для будущего возвращения функции; удаление и перенос групповых данных не выполнялись.

Проверены сборка, типы worker, 30 frontend-тестов (включая сброс устаревшей групповой области в запросах) и 5 серверных тестов групп.
